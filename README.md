# Project Overview

This is consisting of a separate backend and frontend.
The project was originally created using Emergent AI and is now maintained via GitHub.

The repository is intended to be used and evolved with AI-assisted development tools such as Lovable AI.

---

## Project Structure

The repository is organized as follows:

- `/backend`  
  Backend service containing API endpoints, business logic, and server-side functionality.

- `/frontend`  
  Frontend application responsible for the user interface and client-side logic.

- `/tests`  
  Test files covering backend and/or frontend functionality.

- `/test_result.md`  
  Notes and results from test executions.

- `.emergent`  
  Legacy metadata from Emergent AI. This folder is no longer used in active development and should be ignored by tools.

---

## Architecture Notes

- Backend and frontend are intentionally separated.
- They should **not be merged or restructured** unless explicitly requested.
- The backend typically exposes APIs consumed by the frontend.
- No monorepo build system is assumed unless clearly stated.

- Frontend: existing / work in progress

## Important Constraints for AI Tools

When working with this repository:
- Preserve the current folder structure.
- Do not merge backend and frontend.
- Prefer small, incremental changes.
- Explain changes before making them.

This README is intended to clarify project intent for both humans and AI tools.
